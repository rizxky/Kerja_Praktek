# Sistem Absensi Guru Berbasis Web

## Deskripsi
Sistem Absensi Guru Berbasis Web merupakan aplikasi
untuk mengelola kehadiran guru menggunakan teknologi
selfie dan GPS.

## Fitur
- Login Guru
- Login Admin
- Absensi Masuk
- Absensi Pulang
- Verifikasi Selfie
- Validasi Lokasi GPS
- Riwayat Absensi
- Manajemen Data Guru
- Pengelolaan Status Akun Guru
- Reset Password Guru

## Teknologi
- PHP
- MySQL
- HTML
- CSS
- Bootstrap 5
- JavaScript
